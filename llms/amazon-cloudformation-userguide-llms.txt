### [Template sections](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/template-anatomy.md)

Describes the sections that you can use in the JSON or YAML text file that describes your AWS infrastructure.

- [Resources](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/resources-section-structure.md): Define the AWS resources to provision as part of your stack in the Resources section of a CloudFormation template.
- [Parameters](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/parameters-section-structure.md): Customize the resources being provisioned by defining input parameters in the Parameters section of a CloudFormation template.
- [Outputs](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/outputs-section-structure.md): Return one or more values by defining outputs in the Outputs section of a CloudFormation template.
- [Mappings](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/mappings-section-structure.md): Specify conditional values based on a mapping key by defining mappings in the Mappings section of a template.

### [Metadata](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/metadata-section-structure.md)

Use the Metadata section to store additional information in your template.

- [AWS::CloudFormation::Interface](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-cloudformation-interface.md): When you create or update stacks, use the AWS::CloudFormation::Interface metadata key to group and sort parameters in the CloudFormation console.
- [Rules](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/rules-section-structure.md): Describes advanced parameter constraints for resources in the Rules section of an AWS CloudFormation template.
- [Conditions](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/conditions-section-structure.md): Control the provisioning of resources based on logical expressions by using intrinsic functions in the Conditions section of a template.
- [Transform](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/transform-section-structure.md): Declare the macros that CloudFormation processes when you submit your template.
- [Format version](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/format-version-structure.md): Specify the CloudFormation template format version that the template conforms to.
- [Description](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/template-description-structure.md): Provide a description of your template in the Description section of a template.
- [Infrastructure Composer](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/infrastructure-composer-for-cloudformation.md): Use Infrastructure Composer in CloudFormation console mode for a drag-and-drop interface for building templates in the console.
- [AWS CloudFormation Language Server](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/ide-extension.md): Use the AWS CloudFormation Language Server to author, validate, and deploy CloudFormation templates directly within your IDE.

### [Detect unmanaged configuration changes to stacks and resources](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-stack-drift.md)
